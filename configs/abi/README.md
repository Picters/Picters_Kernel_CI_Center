# Xiaomi 17 ABI baseline

`mi17_sm8850.symvers` is the core symbol table from Picters Linux 6.12.23,
source commit `426fc68823f3`, built by Actions run `31012165877`.
Its `module_layout` CRC is `0xe976b219`, the known working July 2026 baseline.

This records the older firmware baseline. A difference does not identify the
Android version or prove incompatibility with newer vendor modules. Builds
upload `kmi-report.json`; release publication requires a matching, validated
baseline. Replace this baseline only after checking the target firmware.
